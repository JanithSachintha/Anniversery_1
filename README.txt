SIX YEARS OF US

1. Keep index.html, style.css and script.js together.
2. Open index.html in Chrome, or use VS Code Live Server.
3. Customize the names, date, photos, memories and letter via Personalize this website.
4. Save & download website exports a single self-contained HTML gift with the editor hidden.

Edit index.html for content/config, style.css for visual design, script.js for game logic.
For custom CSS changes, run through a local web server so the export can read the updated stylesheet. The script also includes a fallback copy of the original CSS for file:// use.
To host the editable source, upload all three files together. To host a gift, upload the exported HTML as index.html.
The surprise letter is a game mechanic, not encrypted or password-protected.
